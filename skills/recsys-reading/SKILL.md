# 论文阅读专栏

由 harness 完成论文核实、全文翻译、界面组织与发布，不运行 `pipeline.py`。可直接复用仓库的离线转换、快照和排版函数；不依赖原作者机器上的论文目录、模型密钥或日报数据库。

## 明确范围

定位仓库根目录，读 `AGENTS.md`、`paper_catalog.json`、Git 状态与现有页面。用户可以指定论文 ID、集合、主题和界面调整；默认沿用现有双专栏结构。只整理界面时保留已有全文，不重新翻译。用户要求发布才执行远端写入，发布目标从当前仓库推导。

## 获取与翻译

读取 [全文与页面流程](references/reading.md)。新增论文先核实官方首次提交日期、作者、公司与固定 `vN` 版本，在独立临时目录下载源码并检查正文、附录、图片和参考文献。TeX 下载失败先换官方来源，不能悄悄用摘要或不完整 PDF 文本替代全文。

已有中文全文先核对版本和完整性后复用；无译文时由 harness 按章节翻译，保留稳定段落标识、术语表与英文对照。若用户明确要求 `$arxiv-latex-translate`，且该 skill 可用则遵循；普通 HTML 阅读任务不强制安装其他私有 skill，也不默认生成中英文 PDF。仅有 PDF 外壳的源码要向用户说明并获得 PDF 转换路径的选择，不能自动套用历史 PPO 例外。

翻译自然语言，不重写整页。完整保留公式、MathML / TeX 注释、实验数值、表格行列和合并关系、代码、原图、引用及锚点；作者和参考文献条目保留原文。工程摘要不能替代中文全文。

## 组织与验证

按引用文档封装可独立重建的 HTML 快照，登记目录并生成论文列表、搜索、主题筛选和双专栏首页。日期用首次提交日，默认最新在前，支持倒序切换；不按修订日或 arXiv ID 猜日期。界面定制遵循用户需求，同时保留已有日报入口。

逐段检查译文，逐项对照公式、表格数值、图与引用，而非只比较数量。测试 1440px / 390px：宽表独立滚动、表注不重叠、数字不断字、短公式基线正常、宽公式可滚动、SVG 标签清晰、链接可跳转。新增论文应有重点截图并人工查看。浏览器不可用时明确记录，不能把单元测试当成视觉验收。

## 交付与发布

阅读 [静态站点发布](../references/publishing.md)。提交 HTML、必要图形、目录和相关界面代码；不上传 PDF、原始源码、缓存或密钥。若用户同时要求本地 PDF，放在被忽略的 `paper_pdfs/source/en/`、`zh/` 并更新相应本地清单，不把它变成页面运行依赖。

发布后检查线上目录、新论文、跳转及图形，确认自动排版与站点验证结果。保存实际日期的 INFO / WARNING / ERROR 日志、版本、来源、内容与视觉检查报告；上线后仅清理本次临时目录，不删除用户论文归档。报告全文范围、已知限制、本地与线上链接。
